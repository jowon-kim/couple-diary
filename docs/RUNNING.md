# 오래 굴리기

깔고 나서 알아야 할 것들입니다. 급하지 않지만 언젠가 걸리는 것들이에요.

## 돈이 나가는 자리 — 없습니다, 다만 조건이 있습니다

쓰는 서비스는 넷이고 **넷 다 무료 구간 안**입니다. 한도를 넘겨도 청구되지 않고
멈춥니다.

| 무엇 | 무료 조건 | 주의 |
|---|---|---|
| **Vercel** (Hobby) | 함수 호출·전송량 월 한도 | **비상업·개인 용도**여야 합니다. 돈을 받으면 Pro가 필요합니다 |
| **Neon** (Free) | 프로젝트당 컴퓨트 100 CU-hour · 저장공간 0.5GB | 아래 참고 |
| **웹푸시** (Apple / Google) | 무료 · 건수 제한 없음 | 계정도 요금도 없습니다 |
| **GitHub** | 무료 | — |

**저장공간은 걱정 안 하셔도 됩니다.** 달력 사진을 꽉 채워 30장 넣어도 base64로
400KB 안팎이라 0.5GB의 0.1%입니다.

**컴퓨트 시간이 유일하게 신경 쓸 값입니다.** Neon은 요청이 오면 깨어나고 5분 놀면
잠듭니다. 깨어 있는 시간만 소모돼요. 0.25 CU면 월 400시간까지 쓸 수 있는데, 둘이
하루 몇 번 열어보는 정도면 월 10시간도 안 됩니다.

- **동기화를 2분보다 자주 하지 마세요.** 더 자주 부르면 DB가 잠들지 못합니다
- 화면을 보고 있을 때만, 10분 이상 안 만지면 쉬도록 이미 짜여 있습니다
- Neon 신규 프로젝트는 기본 최소 컴퓨트가 0.25 CU입니다. **올리지 마세요**

## 손대면 안 되는 것

**`app_meta` 표.** 앱이 처음 켜질 때 스스로 만든 열쇠들이 들어 있습니다
(`lib/setup.js`). 줄을 지우거나 고치면 새로 만들어지는데, 그러면

- `vapid` — 브라우저가 만든 구독에 박혀 있던 키라 **켜둔 기기의 알림이 전부 죽고**
  둘 다 설정에서 다시 켜야 합니다
- `diary_secret` — 로그인 토큰을 여기서 뽑습니다. 둘 다 로그아웃됩니다
- `cron_secret` — 바깥 시계가 401을 받습니다. 설정 화면의 새 주소를 다시 넣어야 해요

## 백업은 직접 하셔야 합니다

Neon 무료 플랜은 6시간 복원 창만 줍니다. 가끔 Neon SQL Editor에서
`select * from events`를 돌려 CSV로 내려받아 두세요.

## 시간이 지나면 손봐야 하는 것

**아이폰 웹푸시가 조용히 끊깁니다.** iOS 쪽 알려진 성질입니다. 앱을 열 때 구독이
사라졌으면 도로 걸어둡니다 — 권한은 남아 있어서 다시 물어보지 않고 조용히 됩니다.
그래도 안 오면 설정에서 껐다 켜세요. 앱을 지웠다 다시 깔면 권한부터 없어집니다.

**공휴일 표가 2036년까지입니다.** 음력에 매인 설날·추석·부처님 오신 날은 계산으로
못 구해서 `public/app.js`의 `LUNAR_DAYS`에 적어두었습니다. 표에 없는 해는 양력
공휴일만 뜨니, 그때 한국천문연구원 발표 날짜를 몇 해 더 붙이면 됩니다.
대체공휴일은 규칙(관공서의 공휴일에 관한 규정 제3조)대로 알아서 붙습니다.

**Node 버전을 안 박아뒀습니다.** `package.json`에 `engines`가 없어서 Vercel
기본값을 따라갑니다. 배포가 경고를 내면 `"engines": { "node": "22.x" }` 같은 줄을
넣으면 됩니다.

**바깥에서 끌어오는 것 둘** — 글꼴입니다.

| 어디서 | 무엇 | 없으면 |
|---|---|---|
| `fonts.googleapis.com` | Gowun Batang (제목) | 기본 명조로 떨어짐 |
| `cdn.jsdelivr.net` | Pretendard (본문) | `-apple-system`으로 떨어짐 |

둘 다 버전을 박아뒀으니 어느 날 모양이 바뀔 일은 없고, CDN이 죽어도 **글꼴만
기본체로 떨어지고 달력은 그대로 돕니다.** 손글씨체는 `public/fonts/`에 넣어뒀습니다.

**라이브러리는 셋뿐입니다.**

| | 쓰는 곳 |
|---|---|
| `@neondatabase/serverless` | DB 연결 |
| `web-push` | 알림 보내기 |
| `@electric-sql/pglite` | 테스트에서만 (`--omit=dev`로 배포엔 안 올라감) |

`npm outdated`로 확인하고, 올린 뒤엔 `npm test`가 통과하는지만 보면 됩니다.

**무료 조건은 회사가 바꿀 수 있습니다.** 위 표는 이 문서를 쓴 시점 기준이라,
1년쯤 뒤에는 Vercel·Neon 요금 페이지를 한 번 확인해 보세요.

## 남에게 서비스로 내주려면

지금 구조는 **한 쌍이 한 벌씩 설치하는 것**을 전제로 합니다. 여러 커플이 한 배포를
같이 쓰면 서로의 일정이 보입니다. 버그가 아니라 설계예요 — `settings` 표는
`check (id = 1)`로 한 줄만 존재할 수 있고, `events`에는 어느 달력인지 적는 칸이
없습니다.

그리고 달력 사진 주소(`/api/photos/...`)는 비밀번호 없이 열립니다. id가 uuid라
찍어서 맞힐 수는 없지만, 주소가 새면 누구나 봅니다.

여러 사람에게 내주려면 계정·테넌트 분리부터 새로 지어야 합니다.
